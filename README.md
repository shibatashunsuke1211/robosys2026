# robosys2026
![test](https://github.com/shibatashunsuke1211/robosys2026/actions/workflows/test.yml/badge.svg)

## kinematicsコマンド
マニピュレータの順運動学解を求めるコマンドです。
ロボットマニピュレータの授業で学んだ計算式を利用しています。
手先の位置と姿勢を求める際の計算や答え合わせに使用できます。

直動関節1つと回転関節3つの構造、および土台に回転関節を
追加した構造に対応しています。
直動関節はz軸方向に移動し、すべての回転軸はz軸と平行です。
追加した土台の回転軸と最初の回転関節の軸は一致するものとします。

## インストール方法
### 必要なソフトウェアのインストール

```
$ sudo apt update
$ sudo apt install git python3
```

### コマンドのダウンロード

```
$ git clone https://github.com/shibatashunsuke1211/robosys2026.git
$ cd robosys2026
```

## 使用方法
標準入力に7個または8個の数値を入力します。

### 7個の数値を入力する場合

```
L1 L2 L3 L4 θ2 θ3 θ4
```

### 8個の数値を入力する場合

```
L1 L2 L3 L4 θ1 θ2 θ3 θ4
```

- L1：直動関節の変位
- L2：第2リンクの長さ
- L3：第3リンクの長さ
- L4：第4リンクの長さ
- θ1：土台の回転角度
- θ2：第2関節の角度
- θ3：第3関節の角度
- θ4：第4関節の角度

長さの単位はmm、角度の単位は度とします。
7個の数値を入力した場合はθ1を0度として計算します。

## 計算式

```
x = L2*cos(θ1+θ2) + L3*cos(θ1+θ2+θ3) + L4*cos(θ1+θ2+θ3+θ4)
y = L2*sin(θ1+θ2) + L3*sin(θ1+θ2+θ3) + L4*sin(θ1+θ2+θ3+θ4)
z = L1
α = θ1 + θ2 + θ3 + θ4
```

入力された角度をラジアンに変換して三角関数の計算を行います。
姿勢角αは度に変換して出力します。

## 実行例

### θ1を指定しない場合

```
$ echo 100 100 100 50 0 90 0 | ./kinematics
100.00 150.00 100.00 90.00
```

### θ1を90度とした場合

```
$ echo 100 100 100 50 90 0 0 0 | ./kinematics
0.00 250.00 100.00 90.00
```

### すべての関節角度を90度とした場合

```
$ echo 100 100 100 50 90 90 90 90 | ./kinematics
-50.00 -100.00 100.00 360.00
```

出力は左から順にx座標、y座標、z座標、姿勢角αです。
座標の単位はmm、姿勢角の単位は度です。
姿勢角は関節角度の合計として出力します。
計算結果は小数点以下2桁で表示します。

## 複数行の入力
複数の条件をまとめて計算することもできます。

```
$ printf "100 100 100 50 0 0 0\n100 100 100 50 90 0 0 0\n" | ./kinematics
250.00 0.00 100.00 0.00
0.00 250.00 100.00 90.00
```

## 異常入力
入力された数値の個数が7個または8個でない場合や、
数値に変換できない文字を入力した場合は、
標準エラー出力にエラーメッセージを表示して異常終了します。

```
$ echo 100 100 | ./kinematics
7 or 8 numbers are required.
```
