# robosys2026
ロボットシステム学の課題で作成したコマンドです。

## kinematicsコマンド
4自由度マニピュレータの順運動学解を求めるコマンドです。
ロボットマニピュレータの授業で学んだ計算式を利用しています。
手先の位置と姿勢を求める際の計算や答え合わせに使用できます。

### 使用方法
標準入力に以下の7つの数値を入力します。

L1 L2 L3 L4 θ2 θ3 θ4

- L1：直動関節の変位
- L2、L3、L4：各リンクの長さ
- θ2、θ3、θ4：各関節の角度

長さの単位はmm、角度の単位は度とします。

### 計算式

```
x = L2*cos(θ2) + L3*cos(θ2+θ3) + L4*cos(θ2+θ3+θ4)
y = L2*sin(θ2) + L3*sin(θ2+θ3) + L4*sin(θ2+θ3+θ4)
z = L1
α = θ2 + θ3 + θ4
```

### 実行例

```
$ echo 100 100 100 50 0 90 0 | ./kinematics
100.00 150.00 100.00 90.00
```

出力は左から順にx座標、y座標、z座標、姿勢角αです。
姿勢角は関節角度の合計として出力します。
計算結果は小数点以下2桁で表示します。

### 複数行の入力
複数の条件をまとめて計算することもできます。

```
$ printf "100 100 100 50 0 0 0\n100 100 100 50 0 90 0\n" | ./kinematics
250.00 0.00 100.00 0.00
100.00 150.00 100.00 90.00
```

### 異常入力
数値の個数が7個でない場合や数値に変換できない文字を
入力した場合は、エラーを表示して異常終了します。

## plus_stdinコマンド
標準入力から読み込んだ数値の合計を求めるコマンドです。

### 実行例

```
$ seq 5 | ./plus_stdin
15
```

